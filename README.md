A live, interactive NLP dashboard built with Streamlit and spaCy. It turns English text into named entities, dependency structure, token metadata, linguistic metrics, semantic similarity, explainable observations, and downloadable results.

The name is a coinage: **Lex-** from Latin *lexicon* (a vocabulary, a dictionary of words). **-scope** from Greek *skopein* (to look, to examine). "A device for looking at words."

---

## Run locally

All commands for this project use the `NLP` conda environment.

```bash
conda activate NLP
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python -m spacy download en_core_web_md
streamlit run app.py
```

Streamlit prints a local URL, usually `http://localhost:8501`. Open it in any browser. The app processes text entirely on your machine. Nothing is uploaded to any server.

## Demo flow

1. Open the app and click **Load sample**. The text appears in the input box.
2. Click **Analyze text**. The pipeline runs in under 50 milliseconds.
3. Walk through the metric row and the entity distribution chart in **Overview**.
4. Show color-coded entity highlighting in **Entities**.
5. Pick a sentence in **Syntax** to explain the dependency graph.
6. Switch the model to **Accurate (en_core_web_md)** in the sidebar and click **Analyze text** again.
7. Open **Similarity** and pick a word like *Google*. Show the in-document neighbors and the vocabulary chips.
8. Finish with deterministic observations and JSON / CSV export in **Insights & export**.

A longer readme lives inside the app at the **About** section. It explains the pipeline, the metrics, the model choice, the project structure, and the reasons behind every technical decision, written for both technical and non-technical readers.

## Models

- `en_core_web_sm` — fast, no vectors. Use for instant reloads.
- `en_core_web_md` — adds 20,000 word vectors. Use for the Similarity tab.

Switch models in the sidebar. The app remembers the chosen model across reruns.

## Deploy to Render (free)

Render hosts the Streamlit app as a free Web Service. The `render.yaml` Blueprint describes the build and runtime.

1. Push this repo to GitHub.
2. Sign in at <https://render.com> with GitHub.
3. Click **New** → **Blueprint**.
4. Connect this repo. Render will detect `render.yaml` and apply it.
5. First build takes 6–10 minutes because the spaCy models install alongside the Python dependencies.
6. The app is available at `https://lexiscope.onrender.com`.

Free tier notes:

- 750 hours of compute per month (enough for a demo).
- Sleeps after 15 minutes of inactivity. The first request after sleep takes 30–60 seconds to wake up.
- 512 MB RAM. `en_core_web_md` loads fine (~600 MB peak), but the cached model and the user session share that memory.

## Notes

- The app processes text locally. No data leaves the machine.
- Input is limited to 20,000 characters to keep live-demo performance predictable.
- Observations are derived from spaCy annotations. They are not generated by an LLM.
- The dashboard deliberately uses classical NLP over a language model for predictability, trust, and speed during live demos.
